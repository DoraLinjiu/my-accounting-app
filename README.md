# 记账本（PWA 版）v1.5.0

大学生多账户记账 App：零依赖、纯离线、**可安装到手机桌面的 PWA 记账 App**——安装后从桌面图标启动，独立窗口打开，没有浏览器地址栏和浏览器角标；也可一键打包成 APK。

> 各版本的升级与修复记录（含原问题、改法、验证数据）见 [CHANGELOG.md](CHANGELOG.md)。

## v1.5.0 更新内容

- **全部账单**：从首页“查看全部”进入完整流水列表，不再受最近记录数量限制
- **自由搜索**：支持搜索分类、账户、备注、金额和日期，并可组合类型、月份、账户筛选
- **筛选汇总**：实时显示匹配笔数、收入合计和支出合计，点任意记录仍可编辑账户或删除
- **视觉重做**：柔雾马卡龙背景、轻透卡片和更清晰的层级；红包改为协调的线性 `¥` 图标

## v1.4.0 更新内容

- **账户安全归档**：有历史流水的账户不再直接删除，归档后保留名称、余额和流水，可随时恢复，总资产不会凭空变化
- **记录可修改账户**：收入/支出可更换所属账户；转账可同时修改转出和转入账户，余额立即重算
- **数据安全**：所有写入失败均会回滚并告知；损坏存档不再被覆盖；导入前严格校验、展示摘要并自动备份当前账本
- **统计更清晰**：修复长自定义范围的首尾月越界；趋势图增加 `¥` 刻度、参考线、柱顶数字和触控详情
- **分类一致性**：删除分类会把历史流水真正迁移到对应的“其他”；默认“其他”受保护
- **红包新图标**：使用暖红色红包外形与清晰的 `¥` 符号，旧存档自动迁移
- **UI 升级**：统一卡片、表单、弹层与间距，增强深色模式、安全区、键盘焦点与减少动画支持
- **部署更灵活**：Manifest 改用相对路径，可部署在根目录或任意 GitHub Pages 子目录

## v1.3 更新内容

- **UI 精致化**：降低色彩噪音、强化层级——总资产卡片改为低饱和马卡龙渐变 + 墨色大数字；账户卡统一白底 + 浅灰描边，颜色只留给图标；记账页分类图标保留马卡龙色相但降饱和、统一成「同色系深一度」；本月汇总数字加大加粗（标签小、数字大）；卡片间距统一 16px；「+」按钮改用主题同款低饱和渐变
- **顶栏昵称改回半透明毛玻璃胶囊**：白字 + 半透明深色圆角底（透明度按真实截图采样定为 0.50——顶栏右端是最浅的马卡龙绿，取 0.15 时白字只有约 1.8:1、取 0.36 实测 3.1:1，都看不清；0.50 实测 4.8:1 且仍透出底色）
- **设置页不再自建安装按钮**：「安装到桌面 / 检查安装条件」按钮已移除，只保留安装说明。原因是自建按钮必须拦截 `beforeinstallprompt`，而拦截后若不再调用 `prompt()`，浏览器自己的「安装应用」入口会被压掉；现在安装入口完全交还浏览器原生 UI
- **文字对比度整体校正**：金额语义色由亮粉/亮绿（白底仅 2.2:1 / 2.8:1）压深到约 4.9:1；次要文字 `--text-sub` 由 3.1:1 提到 4.8:1（深色主题同步提亮）；主按钮白字由 2.2:1 提到 4.6:1 以上；删除按钮、拖拽手柄、开关、选中态图标等一并校正
- **记录可改日期**：编辑面板的日期从只读改成日期选择器（分类 / 备注 / 类型本来就能改，金额与账户保持只读）；保存后首页「月度汇总」与统计页图表同步刷新
- **账户可删除**：账户面板新增「删除这个账户」。账户下已有记录时给两个选择——①**保留记录**（记录里显示「已删除账户」，余额与统计不受影响）②**把记录转移到其他账户**。转账记录不参与搬运：它两侧各属一个账户，搬动会凭空改变另一个账户的余额
- **统计筛选升级**：粒度保留 日/周/月/年 并新增**「自定义」起止日期**；顶部换成 `‹ 期间 ›` 导航条，左右箭头翻期、点中间标题弹出**月份选择器**（年 ‹ › + 12 个月）。自定义跨度 ≤62 天按天分桶，更长自动按月分桶，趋势图不会爆成几百根柱子
- **首页可翻月**：汇总卡片右上角也是 `‹ 2026 年 10 月 ›`，可翻看历史月份；不是当月时标题自动变成「月度汇总」
- **分类可编辑**：分类管理里点整行进入编辑弹窗，可**改名 / 换图标 / 删除**（行内不再放删除按钮，避免和拖拽手柄误触）；删除前会提示该分类下有多少条记录，确认后记录会归到「其他」而不会丢
- **交互与视觉细节**：顶栏昵称胶囊改暖调近黑 + 内阴影（不再是一块纯黑压在浅色上）、并收紧内边距；统计期间导航条间距 6 → 10px；「+」按钮 44 → 38px、上浮与阴影再减一档；微信零钱通与红包的默认图标换成更直白的金币 / 闭合信封（老存档自动迁移，用户自己改过的图标不动）
- **修复：记账时开计算器、点上方空白会退出并丢内容**：现在在计算器界面点上方空白**只会回到记账表单**（已填内容保留），并新增「返回记账（不保存算式）」按钮。原因是计算器原本没有任何返回出口（`onBack` 传进来了却从没被调用），而空白点击的行为是"直接关闭整个弹层"
- 缓存名 `jizhangben-v1.3` → `jizhangben-v1.3-r4`（应用版本仍是 v1.3，用后缀强制刷新一次缓存）
- 版本号 v1.3（store.js VERSION + manifest + SW 缓存名 + 静态资源 ?v= 全部同步）

## 本地运行

PWA 需要 http 环境（Service Worker 不支持 file:// 直开）：

**方式一：双击 `启动记账本.bat`**（推荐）
自动起本地服务 + 打开浏览器，用完直接关掉那个黑窗口即可。
它会自动把本文件夹映射成 `/my-accounting-app/` 再打开
（`http://localhost:8765/my-accounting-app/`），和线上 GitHub Pages 的路径一模一样，
所以在本地装出来的 App 点开也正常，不会 404。

**方式二：手动命令**

```bash
cd accounting-app
python -m http.server 8765
# 开 http://localhost:8765/index.html 也能看到 Install 按钮，
# v1.4.0 起 manifest 使用相对 start_url / scope，手动启动时也可正常安装。
```

## ⚠️ 为什么只能「创建快捷方式」，图标还带浏览器角标？

**原因：用 `file://` 双击 `index.html` 打开时，浏览器读不到 manifest（被 CORS 拦截），
于是认定它只是普通网页，只提供「创建快捷方式」——这种快捷方式带浏览器角标，
点开是浏览器标签页，不是独立 App。**

| 打开方式 | 浏览器表现 |
|---------|-----------|
| 双击 `index.html`（`file://`） | ❌ 只能「创建快捷方式」，图标带浏览器标识 |
| `http://localhost:8765/my-accounting-app/`（本机服务） | ✅ 菜单出现真正的「安装」，独立窗口、无地址栏、图标是记账本自己的 |
| `https://...`（部署后） | ✅ 同上，且手机可「添加到主屏幕」 |

**正确姿势**：先双击 `启动记账本.bat`，浏览器打开 `http://localhost:8765/my-accounting-app/` 后，
点右上角菜单里的**「安装」**（Edge 是「应用 → 将此站点作为应用安装」），
**不要**点「创建快捷方式」。

## 安装到手机桌面（真·PWA，不是快捷方式）

- **安卓 Chrome**：打开 https 网址 → 右上角菜单 → 出现的是**「安装应用」**（不是「添加到主屏幕」）→ 桌面出现记账本图标，点开就是独立窗口，没有地址栏、没有浏览器角标
- **电脑 Chrome**：地址栏右侧出现安装图标，或菜单 →「安装记账本…」；开发者工具 → Application → Manifest 里也能看到 Install 按钮
- **iPhone**：Safari 打开页面 → 分享 →「添加到主屏幕」（iOS 只支持这一种）

> ⚠️ **手机必须用 https 网址打开才可能出现「安装应用」**。Chrome 只在 **https**（或本机 localhost）下才把网页当成可安装的 App；
> 用 `http://电脑IP:8765` 这种局域网 http 地址打开，浏览器不会给真正的安装入口，只会给一个带浏览器角标的快捷方式。
> 所以要在手机上装成真 App，请先按下面把文件部署到 GitHub Pages / Vercel，拿到 https 网址再装。

## 免费部署（手机访问的前提）

任选其一，全部免费：

1. **GitHub Pages**：新建仓库 → 上传本文件夹全部文件 → Settings → Pages → 选 main 分支 → 得到 `https://用户名.github.io/仓库名/`
2. **Vercel / Netlify**：拖拽本文件夹到 vercel.com 或 netlify.com → 秒得网址

> v1.4.0 起 `manifest.webmanifest` 的 `start_url` / `scope` / `id` 均使用相对路径。仓库名不再需写死，
> 在网站根目录、GitHub Pages 任意仓库子目录或本地 HTTP 服务中均可正常安装。

## 打包成 APK

**方式一：PWABuilder（推荐，零安装）**

1. 先按上文部署得到 https 网址
2. 打开 [pwabuilder.com](https://www.pwabuilder.com) → 输入网址 → Start
3. 进入「Android」→「Download Package」→ 得到 APK/AAB
4. APK 传到手机直接安装（AAB 用于上架应用商店）

**方式二：Bubblewrap（命令行，需 JDK 17 + Android SDK）**

```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest https://你的网址/manifest.webmanifest
bubblewrap build   # 产出 app-release-signed.apk
```

## 说明

- 数据只存在本机浏览器里，卸载 App 或清浏览器数据前请先在「设置 → 导出备份」。
- **图标使用本地化的 Font Awesome Free 6.5.0**：CSS 与所需字体位于 `vendor/fontawesome/`，并由 Service Worker 作为核心资源预缓存，首次安装后无网也能正常显示图标。许可证见 `vendor/fontawesome/LICENSE.txt`。
- 如需云同步（Supabase），在 store.js 的 save() 里追加推送逻辑即可，数据结构已经是纯 JSON。
- 若以后要 Flutter 原生版，数据模型（store.js）和页面划分可 1:1 映射成 Dart 类。
